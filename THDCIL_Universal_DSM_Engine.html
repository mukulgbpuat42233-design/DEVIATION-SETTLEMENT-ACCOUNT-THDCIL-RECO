📊 Google Sheets DSM Template (7 Parameters · 7 Din Ka Data · MWh Unit)

Google Sheets aur Excel compatible template. Saara energy data strictly MWh (Megawatt-hour) me hi bharna hoga.
MWh Unit Mandate
7 Parameters Overview (7 Din ka Data Alag-Alag Tabs ya Master Columnar Sheet):
1. Schedule (MWh)
बेस शेड्यूल्ड जनरेशन (Base Generation Schedule per 15-min block)
2. SRAS (MWh)
सेकेंडरी रिज़र्व (Secondary Ancillary: Up > 0, Down < 0 in MWh)
3. TRAS (MWh)
टर्शियरी रिज़र्व (Tertiary Ancillary: Up > 0, Down < 0 in MWh)
4. Actual Injection (MWh)
वास्तविक जनरेशन / मीटरिंग (Metered generation strictly MWh)
5. Grid Frequency (Hz)
ग्रिड फ्रीक्वेंसी (15-min average grid frequency, e.g. 49.95 Hz)
6. Reference Rate (₹/kWh)
अनुबंध दर / पीपीए दर (Contract rate / Reference tariff in ₹/kWh)
7. DSA Charges (₹)
प्राधिकरण विचलन शुल्क (Official statement charge for 99.99% reconciliation)
⚡ Formula Mandate: Net Schedule (MWh) = Schedule + SRAS + TRAS  |  Net Deviation (MWh) = Actual - Net Schedule

Regime: CERC 2024/2026 Statutory
Grid / Settlement Schedule Revision Management
R0 / R1 / R2 / R3 / R4 / R5 … — latest applicable grid/settlement-authority-issued schedule is used for DSM.
Source / Authority: Selected Grid / Settlement Authority issues and implements schedule revisions through its scheduling systems. The app stores the revision as an auditable record and applies it block-wise only from its effective time. UPSLDC publicly describes web-based scheduling/revision and implemented schedules as part of its scheduling functions.
